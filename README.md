# eticaret
🎮 GamerDükkan: Influencer & Sadakat Tabanlı E-Ticaret Platformu
GamerDükkan, geleneksel e-ticaret modelini sosyal medya etkileşimi ve oyunlaştırma (gamification) ile birleştiren bir Affiliate Marketing prototipidir. Kullanıcıların markanın birer pazarlama elçisine (Mikro-Influencer) dönüştüğü bu sistemde, sosyal medya paylaşımları üzerinden puan kazanımı ve ödül takibi yapılmaktadır.

🚀 Öne Çıkan Özellikler
Google Auth Entegrasyonu: Firebase Authentication ile güvenli ve hızlı kullanıcı girişi.

Kanal Bazlı Takip: Instagram, WhatsApp ve Twitter üzerinden gelen trafiklerin ayrı ayrı izlenmesi.

Influencer Paneli: Tıklanma (Click), Satışa Dönüşüm (Conversion) ve Kazanç verilerinin gerçek zamanlı takibi.

Oyunlaştırma (Tier System): Bronz, Gümüş ve Altın rütbe sistemiyle kullanıcı motivasyonu.

Ödül Marketi: Kazanılan puanların indirim kuponlarına dönüştürülebildiği entegre market.

🛠️ Kullanılan Teknolojiler
Frontend: HTML5, CSS3 (Modern & Responsive UI), JavaScript (ES6+).

Backend: Firebase (Authentication & Realtime Database).

Deployment: Vercel & GitHub CI/CD.
